SUMMARY TABLE - ALL CONFIGURATIONS
================================================================================

This table provides a quick reference of all HIGH and LOW coherence configurations
for all 8 RDF synthetic data generators.

All configurations use LUBM (univ-bench.owl) ontology or LUBM-like structure.
All runs: 10 (number of experimental runs unless specified otherwise)

================================================================================
1. BSBM - Berlin SPARQL Benchmark (E-commerce)
================================================================================

HIGH COHERENCE (BSBM_HIGH_COHERENCE):
  products:         100000
  format:           ttl
  forward_chaining: True
  Expected Output:  output/dataset.ttl (~3-4 GB, ~35M triples)

LOW COHERENCE (BSBM_LOW_COHERENCE):
  products:         50000
  format:           ttl
  forward_chaining: True
  Expected Output:  output/dataset.ttl (~1.5-2 GB, ~17.5M triples)

Key Difference:  Scale of products (products parameter controls density)
Coherence Control: LIMITED (scale only)
Command:          python3 BSBM/execute_benchmark.py --products [100000|50000]

================================================================================

  instances:        110000
  materialization:  True   ← KEY PARAMETER
  Expected Output:  output/gaia_instances.owl (~1,650,000-2,200,000 triples, ~20-30 MB)

LOW COHERENCE (GAIA_LUBM_LOW_COHERENCE):

  Expected Output:  output/gaia_instances.owl (~550,000-770,000 triples, ~10-15 MB)

  distribution:     gaussian      ← KEY PARAMETER (even coverage)

  Expected Output:  output/data_*.nt (~150K distinct triples)

LOW COHERENCE (LINKGEN_LUBM_LOW_COHERENCE):
  triples:          150000  (same count, different distribution)

  threads:          4
  Expected Output:  output/data_*.nt (~150K distinct triples, varied coverage)

Key Difference:  Statistical distribution (gaussian vs. Zipf)
Coherence Control: EXCELLENT (distribution directly affects property frequency patterns)
Command:          python3 LINKGEN/execute_benchmark.py --triples 150000 --distribution [gaussian|zipf]

5. PYGRAFT - Schema and Knowledge Graph Generator
================================================================================

HIGH COHERENCE (PYGRAFT_HIGH_COHERENCE):
  mode:             full
  n_classes:        43           (LUBM-like)
  n_relations:      32
  max_depth:        150          ← HIGH COHERENCE (many, consistent)
  std_instances:    40           ← MODERATE STD
  avg_relations:    5            ← HIGH (complete property coverage)
  std_relations:    1            ← LOW STD (uniform)
  p_subclass:       0.25
  p_disjoint:       0.10
  p_functional:     0.05         ← LOW (non-deterministic)
  p_symmetric:      0.15
  p_transitive:     0.15
  Expected Output:  output/rdf_data.xml (~1 million triples, ~20-40 MB)

LOW COHERENCE (PYGRAFT_LOW_COHERENCE):
  mode:             full
  n_classes:        43           (LUBM-like, same)
  n_relations:      32           (same)
  max_depth:        4            (same)
  avg_instances:    150          ← SAME as high (required for stability)
  std_instances:    40           ← SAME STD (required for stability)
  avg_relations:    2            ← LOW (sparse property coverage)
  std_relations:    2            ← HIGH STD (varied)
  p_subclass:       0.25         ← SAME (same schema)
  p_disjoint:       0.10         ← SAME
  p_functional:     0.05         ← SAME
  p_symmetric:      0.15         ← SAME
  p_transitive:     0.15         ← SAME
  Expected Output:  output/rdf_data.xml (~200 K triples, ~4-8 MB)

Key Difference:  Relation counts (5 vs. 2) and relations std dev (1 vs. 2)
Coherence Control: EXCELLENT (multiple parameters for fine-grained control)
Command:          python3 PYGRAFT/execute_benchmark.py --mode full --n-classes 43 \
                    --avg-instances 150nchmark.py --mode full --n-classes 43 \
                    --avg-instances [200|50] --avg-relations [5|2] --std-relations [1|2]

7. RUDOFGENERATE - ShEx/SHACL High-Performance Generator
================================================================================

HIGH COHERENCE - SHEX (RUDOFGENERATE_LUBM_SHEX_HIGH_COHERENCE):
  schema:           lubm.shex
  config_file:      benchmark_config_high_coherence.toml
  cardinality_strategy: Maximum  ← KEY PARAMETER
  entity_count:     70000
  property_fill_probability: 1.0  (100%)
  property_selection_strategy: All
  quality:          High
  Expected Output:  output/generated_data.ttl (~700K-1M triples, ~20-30 MB)

LOW COHERENCE - SHEX (RUDOFGENERATE_LUBM_SHEX_LOW_COHERENCE):
  schema:           lubm.shex
  config_file:      benchmark_config_low_coherence.toml
  cardinality_strategy: Maximum  (same, but selective property use)
  entity_count:     70000        (same count)
  property_fill_probability: 0.25 (25%)
  property_selection_strategy: Random ← KEY PARAMETER
  quality:          Low
  Expected Output:  output/generated_data.ttl (~175K-250K triples, ~5-10 MB)

HIGH COHERENCE - SHACL (RUDOFGENERATE_LUBM_SHACL_HIGH_COHERENCE):
  schema:           lubm_shacl.ttl
  config_file:      benchmark_config_high_coherence.toml
  (Same config as ShEx variant)
  Expected Output:  output/generated_data.ttl (~700K-1M triples, ~20-30 MB)

LOW COHERENCE - SHACL (RUDOFGENERATE_LUBM_SHACL_LOW_COHERENCE):
  schema:           lubm_shacl.ttl
  config_file:      benchmark_config_low_coherence.toml
  (Same config as ShEx variant)
  Expected Output:  output/generated_data.ttl (~175K-250K triples, ~5-10 MB)

Key Difference:  Property selection strategy (All vs. Random) + property_fill_probability
Coherence Control: EXCELLENT (direct control via TOML config + property fill parameters)
Command:          python3 RUDOFGENERATE/execute_benchmark_binary.py \
                    --schema [lubm.shex|lubm_shacl.ttl] \
                    --config [benchmark_config_high_coherence.toml|benchmark_config_low_coherence.toml]

================================================================================
QUICK REFERENCE - GENERATOR SELECTION
================================================================================

Use BSBM if:
  - Need e-commerce domain data
  - Want to test SPARQL benchmarks
  - Need baseline comparison

Use LUBM if:
  - Need academic/university domain
  - Want highly structured reference data
  - Need baseline coherence comparison

Use GAIA if:
  - Want to study materialization effects
  - Need controllable coherence via materialization
  - Test OWL reasoning implementations

Use LINKGEN if:
  - Want statistical distribution control
  - Test realistic LOD patterns (Zipf)
  - Study distribution effects on coherence

Use PYGRAFT if:
  - Need maximum coherence control flexibility
  - Want both schema and data generation
  - Require OWL semantics and consistency

Use RDFGRAPHGEN if:
  - Want SHACL-based generation
  - Need W3C standard compliance
  - Scale factor is simple/intuitive control

Use RUDOFGENERATE if:
  - Need fastest generation (Rust binary)
  - Want fine-grained configuration
  - Need both ShEx and SHACL support
  - Working with large-scale benchmarks

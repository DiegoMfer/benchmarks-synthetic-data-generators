================================================================================
GAIA - Ontology Instance Generator (LUBM)
================================================================================

Tool Information:
  Name: GAIA (Generator for Automatic Instanciation)
  Version: 3.1
  Type: OWL ontology-based instance generator
  Purpose: Generate synthetic instances from OWL ontologies
  Ontology: univ-bench.owl (LUBM)
  Location: GAIA/ directory
  Script: execute_benchmark.py

Technical Details:
  Language: Java
  Key Feature: Materialization option (infers superclass properties)
  Download: Automatically downloads LUBM ontology on first run
  URL: http://swat.cse.lehigh.edu/onto/univ-bench.owl

================================================================================
HIGH COHERENCE CONFIGURATION
================================================================================

Name: GAIA_LUBM_HIGH_COHERENCE
Goal: Full materialization ensures complete property coverage

Parameters:
  instances: 110000                   # Number of instances to generate
  materialization: True              # KEY PARAMETER - Enable property inference
  runs: 10                           # Number of experimental runs

Execution:
  Command: python3 GAIA/execute_benchmark.py --instances 110000 --materialization
  Or: ./run-benchmark.sh 110000 true
  Or: python3 execute_benchmark.py -n 110000 -m

Coherence Rationale:
  - materialization=True INFERS and ADDS implicit properties
  - Every instance receives explicit values for INFERRED properties
  - Complete property coverage across all instance types
  - Superclass properties are materialized to subclass instances
  - Creates DENSE, COMPLETE data structure
  - Similar to normalization + materialization in databases

Property Materialization Example:
  - Base: Person instance with name, age
  - Materialized: Person + Student + GraduateStudent properties (if applicable)
  - Result: Each instance has ALL properties from full class hierarchy
  - Coherence Effect: MAXIMUM (all properties present)

Expected Output:
  - File: output/gaia_instances.owl
  - Instances: 110,000
  - Triples: ~1,650,000-2,200,000 (depends on ontology complexity)
  - File Size: ~20-30 MB

Report Output: output/benchmark_report.json

================================================================================
LOW COHERENCE CONFIGURATION
================================================================================

Name: GAIA_LUBM_LOW_COHERENCE
Goal: No materialization results in sparse property coverage

Parameters:
  instances: 110000                   # Same number of instances
  materialization: False             # KEY PARAMETER - Disable property inference
  runs: 10                           # Number of experimental runs

Execution:
  Command: python3 GAIA/execute_benchmark.py --instances 110000
  Or: ./run-benchmark.sh 110000 false
  Or: python3 execute_benchmark.py -n 110000

Coherence Rationale:
  - materialization=False means ONLY explicit properties are present
  - No inference of superclass properties into instances
  - Each instance only has base class properties
  - Sparse, INCOMPLETE property coverage
  - Classes don't inherit parent properties in output
  - Properties vary significantly between instances

Property Coverage Example:
  - No Materialization: Person instance has only direct Person properties
  - Superclass properties are NOT added to subclass instances
  - Result: Instance only has subset of potential properties
  - Coherence Effect: MINIMUM (few properties present)

Expected Output:
  - File: output/gaia_instances.owl
  - Instances: 110,000 (same count)
  - Triples: ~550,000-770,000 (fewer due to no materialization)
  - File Size: ~10-15 MB (smaller than high coherence)

Report Output: output/benchmark_report.json

================================================================================
CONFIGURATION OPTIONS
================================================================================

Parameters:
  -n, --instances N       # Number of instances to generate (default: 3)
  -l, --limit N          # Maximum instances per class (optional)
  -m, --materialization  # Enable materialization flag
  -t, --threads N        # Number of threads (optional)
  -o, --output FILE      # Output file path

Instances Scale Examples:
  - 1,000 instances: ~20-30K triples (high), ~10-15K (low)
  - 5,000 instances: ~75-100K triples (high), ~40-50K (low)
  - 10,000 instances: ~150-200K triples (high), ~80-100K (low)
  - 50,000 instances: ~750K-1M triples (high), ~400-500K (low)

Class Hierarchy (from LUBM):
  - University (1)
  - Department (50)
  - Faculty (750)
  - Student (1,450)
  - Course (200)
  - Publication (5,000+)
  - ResearchArea (50+)

Property Inheritance Chain Example:
  Hierarchy: Person → Faculty → Professor
  
  Materialization=True adds all properties:
    - Person: name, email, phone
    - Faculty: teaches, research, workFor
    - Professor: degree, specialization
    Result: Professor instance has all 10+ properties

  Materialization=False keeps only direct properties:
    - Professor: only Professor-specific properties
    Result: Professor instance has 2-3 properties

Memory Usage:
  - 1,000 instances: 512MB
  - 5,000 instances: 2GB
  - 10,000 instances: 4GB
  - 50,000+ instances: 8GB+

Generation Time:
  - 1,000 instances: 2 seconds
  - 5,000 instances: 10 seconds
  - 10,000 instances: 20 seconds
  - Scales linearly with instance count

================================================================================
COHERENCE CONTROL MECHANISM
================================================================================

GAIA's Unique Feature for Coherence Control:

The MATERIALIZATION parameter is the PRIMARY coherence control:

1. HIGH COHERENCE (materialization=True):
   - Performs transitive closure of class hierarchy
   - Adds superclass properties to all instances
   - Creates COMPLETE property sets
   - Similar to database view materialization
   - Every instance type has FULL property coverage
   - Coherence ≈ 1.0

2. LOW COHERENCE (materialization=False):
   - No class hierarchy expansion
   - Only explicit instance properties
   - Sparse property coverage
   - Each type has MINIMAL properties
   - Simulates INCOMPLETE data extraction
   - Coherence ≈ 0.3-0.5

This makes GAIA particularly useful for studying materialization effects on data coherence.

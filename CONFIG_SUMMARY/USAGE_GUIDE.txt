================================================================================
QUICK START - INDIVIDUAL GENERATOR EXECUTION
================================================================================

Each generator has its own execute_benchmark.py script in its directory.
Run directly from the generator folder or use the root-level orchestrator.

---
EXAMPLE 1: Run BSBM High Coherence
---

Navigate to BSBM folder:
  cd BSBM

Run with high coherence parameters:
  python3 execute_benchmark.py --products 50000 --format ttl

Or from root:
  python3 BSBM/execute_benchmark.py --products 50000 --format ttl

Output location:
  BSBM/output/dataset.ttl
  BSBM/output/benchmark_report.json

---
EXAMPLE 2: Run GAIA Low Coherence
---

Navigate to GAIA folder:
  cd GAIA

Run with low coherence parameters:
  python3 execute_benchmark.py --instances 10000

(No --materialization flag = materialization=False = low coherence)

Output location:
  GAIA/output/gaia_instances.owl
  GAIA/output/benchmark_report.json

---
EXAMPLE 3: Run LINKGEN with Zipf Distribution
---

Navigate to LINKGEN folder:
  cd LINKGEN

Run with low coherence (Zipf distribution):
  python3 execute_benchmark.py --triples 6000 --distribution zipf --ontology univ-bench.owl

Output location:
  LINKGEN/output/data_*.nt
  LINKGEN/output/benchmark_report.json

---
EXAMPLE 4: Run PYGRAFT High Coherence
---

Navigate to PYGRAFT folder:
  cd PYGRAFT

Run with high coherence parameters:
  python3 execute_benchmark.py --mode full --n-classes 43 \
    --avg-instances 200 --avg-relations 5 --std-relations 1

Output location:
  PYGRAFT/output/rdf_data.xml
  PYGRAFT/output/schema.rdf
  PYGRAFT/output/benchmark_report.json

---
EXAMPLE 5: Run RUDOFGENERATE High Coherence
---

Navigate to RUDOFGENERATE folder:
  cd RUDOFGENERATE

Run with high coherence parameters:
  python3 execute_benchmark_binary.py --schema lubm.shex \
    --entity-count 20000 --cardinality-strategy Maximum

Output location:
  RUDOFGENERATE/output/generated_data.ttl
  RUDOFGENERATE/output/generated_data.stats.json
  RUDOFGENERATE/output/benchmark_report.json

================================================================================
DOCKER EXECUTION
================================================================================

Each generator supports Docker execution. Use these commands from the
respective generator directory:

---
BSBM Docker
---

Build:
  ./build-docker.sh

Run High Coherence:
  docker run --rm -v $(pwd)/output:/app/output bsbm-benchmark --products 50000

Run Low Coherence:
  docker run --rm -v $(pwd)/output:/app/output bsbm-benchmark --products 10000

Docker Compose:
  docker-compose run --rm bsbm-benchmark --products 50000

---
LUBM Docker
---

================================================================================
BATCH EXECUTION - ALL GENERATORS
================================================================================

The root-level orchestrator allows running multiple or all generators at once.

---
Run ALL Generators (All Coherence Variants)
---

From root directory:
  python3 generate_all_datasets.py

This runs:
  - BSBM (high + low)
  - LUBM (high + low)
  - GAIA (high + low)
  - LINKGEN (high + low)
  - PYGRAFT (high + low)
  - RDFGRAPHGEN (high + low)
  - RUDOFGENERATE ShEx (high + low)
  - RUDOFGENERATE SHACL (high + low)

Output location: 1-Datasets/[GENERATOR_NAME]/run_N/

---
Run Specific Generators Only
---

Example 1: Run only BSBM
  python3 generate_all_datasets.py --generators BSBM_HIGH_COHERENCE BSBM_LOW_COHERENCE

Example 2: Run LUBM and GAIA
  python3 generate_all_datasets.py --generators LUBM_HIGH_COHERENCE LUBM_LOW_COHERENCE \
    GAIA_LUBM_HIGH_COHERENCE GAIA_LUBM_LOW_COHERENCE

Example 3: Run only high coherence variants
  python3 generate_all_datasets.py --generators \
    BSBM_HIGH_COHERENCE LUBM_HIGH_COHERENCE GAIA_LUBM_HIGH_COHERENCE \
    LINKGEN_LUBM_HIGH_COHERENCE PYGRAFT_HIGH_COHERENCE \
    RDFGRAPHGEN_LUBM_HIGH_COHERENCE RUDOFGENERATE_LUBM_SHEX_HIGH_COHERENCE \
    RUDOFGENERATE_LUBM_SHACL_HIGH_COHERENCE

---
Custom Output Directory
---

By default, datasets are saved to 1-Datasets/
To use a custom directory:
  python3 generate_all_datasets.py --dataset-dir my-custom-dir

Output: my-custom-dir/[GENERATOR_NAME]/run_N/

================================================================================
GENERATE METRICS
================================================================================

After running generators, produce comparison metrics:

From root directory:
  python3 generate_csv_metrics.py

This produces:
  - metrics_comparison.csv (with RDF_Coherence scores)
  - Parses benchmark_report.json from each generator
  - Computes coherence metrics
  - Organizes by dataset type and run number

Output file: metrics_comparison.csv

Metrics included:
  - Generator name
  - Run number
  - Execution time
  - Number of triples
  - Triples per second
  - RDF_Coherence score
  - File size

================================================================================
CONFIGURATION MODIFICATION
================================================================================

To modify configurations:

1. Direct Python Edit:
   Edit generate_all_datasets.py
   Function: get_benchmark_configurations()
   Update the returned dictionary with new parameters

2. Individual Generator Parameters:
   Each generator accepts command-line parameters
   See individual configuration files for full parameter lists

3. RUDOFGENERATE TOML Files:
   Edit benchmark_config_high_coherence.toml
   Edit benchmark_config_low_coherence.toml
   Located in RUDOFGENERATE/ directory

4. PYGRAFT Configuration:
   Modify execute_benchmark.py
   Or pass parameters directly: --avg-instances 250 --avg-relations 6

================================================================================
TYPICAL WORKFLOW
================================================================================

1. Preparation:
   $ cd /path/to/benchmarks-synthetic-data-generators

2. Run Single Generator Test:
   $ python3 BSBM/execute_benchmark.py --products 1000 --format ttl
   Check: BSBM/output/benchmark_report.json

3. Run High Coherence Variants:
   $ python3 generate_all_datasets.py --generators \
     BSBM_HIGH_COHERENCE LUBM_HIGH_COHERENCE GAIA_LUBM_HIGH_COHERENCE \
     LINKGEN_LUBM_HIGH_COHERENCE PYGRAFT_HIGH_COHERENCE \
     RDFGRAPHGEN_LUBM_HIGH_COHERENCE RUDOFGENERATE_LUBM_SHEX_HIGH_COHERENCE \
     RUDOFGENERATE_LUBM_SHACL_HIGH_COHERENCE

4. Generate Metrics:
   $ python3 generate_csv_metrics.py

5. Analyze Results:
   $ cat metrics_comparison.csv | column -t -s,

6. Visualize (if Jupyter installed):
   $ jupyter notebook metrics_histogram.ipynb

================================================================================
PARAMETER REFERENCE BY GENERATOR
================================================================================

Quick parameter lookup for each generator:

BSBM:
  --products N              (default: 1000)
  --format FMT              (ttl, nt, n3, trig)
  --no-fc                   (disable forward chaining)
  --output-name NAME
  --output-dir DIR

LUBM:
  --universities N          (default: 1)
  --seed N                  (default: 0)
  --format FMT              (owl, daml)
  --index N

GAIA:
  --instances N             (default: 3)
  --materialization         (flag, no value)
  --limit N
  --threads N
  --output FILE

LINKGEN:
  --triples N               (default: 100000)
  --ontology FILE
  --distribution TYPE       (zipf, gaussian, uniform)
  --threads N               (default: 2)
  --format FMT              (nt, nq)
  --zipf-exponent VALUE     (default: 2.1)
  --gaussian-mean VALUE     (default: 200)
  --gaussian-deviation VAL  (default: 15)

PYGRAFT:
  --mode MODE               (schema, kg, full)
  --n-classes N             (default: 50)
  --n-relations N           (default: 30)
  --max-depth N             (default: 5)
  --avg-instances N         (default: 50)
  --std-instances N         (default: 10)
  --avg-relations N         (default: 3)
  --std-relations N         (default: 1)
  --p-subclass P            (probability 0-1)
  --p-functional P
  --seed N                  (default: 42)

RDFGRAPHGEN:
  --scale-factor N          (default: 100)
  --shape FILE              (default: input-shape.ttl)
  --output FILE             (default: output-graph.ttl)
  --output-dir DIR

RUDOFGENERATE:
  --schema FILE
  --entity-count N          (default: 100)
  --cardinality-strategy S  (Minimum, Maximum, Random, Balanced)
  --worker-threads N        (default: 4)
  --batch-size N            (default: 100)
  --output-format FMT       (Turtle, NTriples, etc.)

================================================================================
TROUBLESHOOTING
================================================================================

Issue: "Java not found"
Solution: Install Java 17+ and ensure JAVA_HOME is set
  export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64
  java -version  # Verify

Issue: "OutOfMemoryError"
Solution: Increase JVM memory
  Modify execute script or add: -Xmx8g parameter to java command

Issue: "Docker not found"
Solution: Install Docker and ensure daemon is running
  docker --version
  sudo systemctl start docker

Issue: "rdfgen command not found" (RDFGraphGen)
Solution: Install Python package
  pip install rdf-graph-gen

Issue: "Generator not producing output"
Solution: Check output directory permissions
  chmod -R 755 GENERATOR_NAME/output

Issue: "LUBM ontology download failed"
Solution: Ensure internet connection, or download manually:
  wget http://swat.cse.lehigh.edu/onto/univ-bench.owl
